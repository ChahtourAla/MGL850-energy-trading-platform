# B23 offline test evidence

Baseline `8e970f36ff51642795eced944b481f46d8ea7ebf`, branch `feature/b23-direct-settlement-contract`. No live blockchain access or deployment was made. Node v22.20.0 is below the backend minimum 22.22.3. Contract tests use the Hardhat in-process simulated network.

- From `packages/contracts`: `node_modules/.bin/hardhat.cmd compile` compiled the new contract with solc 0.8.34, EVM Cancun. The initial build found a stack-too-deep error; moving event emission into a private helper resolved it. The final `node_modules/.bin/hardhat.cmd test` freshly compiled the changed contract and passed **85 tests**, including 17 B23 tests and 68 legacy tests. After adding three additional role, token-domain and builder tests, `node_modules/.bin/hardhat.cmd test --no-compile` passed **88 tests** (20 B23 and 68 legacy); Solidity source was unchanged since that fresh compilation. Local mock tests cover false return, revert, fee transfer and reentry; other tests exercise authorization, terms, domains, nonce, duplicate allocation, plan/snapshot pin, allowance, balance and pause. Local EIP-712 digest matches the contract, and a static shared vector is checked in TypeScript.
- From `packages/contracts`: `node_modules/.bin/tsc.cmd --noEmit` passed after typing the test's dynamic mock/token contract explicitly. It should be repeated if TypeScript files change.
- Root Node: `$env:B21_PYTHON=(Resolve-Path '.venv/Scripts/python.exe').Path; $tests=@(Get-ChildItem apps/backend/scripts,tools,packages/shared/tests -Filter '*.test.mjs' -File | ForEach-Object { $_.FullName }); node --test @tests` passed **1383** tests.
- `.venv/Scripts/python.exe -m pytest --import-mode=importlib -p no:cacheprovider -q`: **608 passed**.
- Backend local `vitest.cmd run`: **171 passed** in 22 files. Local `tsc.cmd --noEmit`, `oxlint.cmd src test`, root Prisma `validate` and `generate` passed.
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/b22-run-postgres-tests.ps1`: passed in a dedicated loopback disposable PostgreSQL container.
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/b21-run-postgres-tests.ps1`: first run failed in a concurrent snapshot test during heavy parallel load; a separate retry passed fresh and legacy-populated migrations, constraints and concurrency checks, and reported legacy records unchanged. The initial failure was not ignored or proven harmless.

The contract's matching-input/plan correctness, production role provisioning, real token address/code, Hedera receipt verification, cross-deployment duplicate prevention, key custody and consent remain future responsibilities. Local test results are not a production audit. The reusable TypeScript builder relies on its caller to obtain a truly authoritative B22 plan and validate complete allocations, not merely caller-provided status strings.
