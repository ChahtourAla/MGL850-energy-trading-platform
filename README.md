Decentralized peer-to-peer energy trading platform developed for MGL850.

## Technology Stack

- Node.js >= 22
- pnpm
- NestJS
- PostgreSQL
- Prisma
- Python
- FastAPI
- Solidity
- Hardhat
- Hedera
- Next.js
- Docker
