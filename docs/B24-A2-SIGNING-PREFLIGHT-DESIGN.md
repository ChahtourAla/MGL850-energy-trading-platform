# B24-A2 independent preflight

B24-A1 reserves immutable unsigned terms. B24-A2 reads by reservation ID, under a distinct non-owner `b24_preflight` login and a read-only repeatable-read transaction. It reuses B22 historical source and accounting reconciliation, recomputes the B21 allocation identities and the complete B23 allocation-set commitment, reconstructs B23 terms with bigint arithmetic and checks the EIP-712 digest and every stored JSON field. It checks fixture fingerprints, policy scope, active status, exact reserved budget, nonce uniqueness and deadline. No caller-supplied terms are authority.

PostgreSQL `transaction_timestamp()` is the trusted snapshot time, supplemented by `clock_timestamp()` before return, with at least 60 seconds remaining. Clock synchronization between PostgreSQL, application servers and future blockchain block timestamps must be monitored; the minimum margin is not a guarantee of future inclusion. Policy status can change after the snapshot. A concurrent revocation can commit while a preflight still sees the previous snapshot: B24-B must independently perform a fresh policy, deployment, complete plan and typed-data verification at its own controlled signing boundary. A preflight is never a durable grant.

The `SIMULATION_ELIGIBLE` state means only a synthetic fixture passed these offline checks. It is not human consent or permission to sign a real wallet. It proves neither on-chain balance, allowance, nonce availability nor deployment. The DB owner remains trusted. PostgreSQL itself does not verify the Keccak digest. An immutable policy ID refers to its stored immutable version; the B24-A1 reservation does not separately store a policy-version number.

Run `powershell -NoProfile -ExecutionPolicy Bypass -File tools/b24a2-run-postgres-tests.ps1` from the root with the local PostgreSQL 17 image, Docker, dependencies and B23 artifact installed. This creates and destroys only its own labeled container. No production database should be used. B24-B signing and B24-C funding remain unimplemented.
